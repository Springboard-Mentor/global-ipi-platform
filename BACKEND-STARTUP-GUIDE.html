🔧 Troubleshooting:

If you see "Port 8080 already in use":

$process = Get-NetTCPConnection -LocalPort 8080 -ErrorAction SilentlyContinue | Select-Object -ExpandProperty OwningProcess -First 1; if ($process) { Stop-Process -Id $process -Force; Write-Host "Port 8080 freed!" } else { Write-Host "Port 8080 is already free" }

Then try starting backend again.
