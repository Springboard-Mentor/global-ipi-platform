🚀 Patent Filing Backend Startup Guide

⚠️ IMPORTANT: Backend Must Be Running!

The form will NOT work unless the backend server is running on port 8080.

Step 1: Open PowerShell Terminal

Open a NEW PowerShell window (not in VS Code terminal)

Step 2: Navigate to Backend Directory

cd "C:\Users\vikas\OneDrive\Desktop\New folder (2)\global-ipi-platform\backend\backend"

Step 3: Start the Backend

.\mvnw spring-boot:run

Wait until you see this message:

Started BackendApplication in X.XXX seconds

✅ What Happens When Backend Starts:

  • ✅ Creates `patent_filings` table in PostgreSQL automatically
  • ✅ Loads all API endpoints including `/api/patent-filing/*`
  • ✅ Connects to database `my_project_db`
  • ✅ Form will work perfectly!

Step 4: Verify Backend is Running

Open browser and go to:

http://localhost:8080/api/patent-filing/status/submitted

Should return: [] (empty array)

Step 5: Test the Form

  1. Open frontend: http://localhost:5173
  2. Login with a NON-BASIC user
  3. Click "Patent Filing" in sidebar
  4. Fill out the form (5 steps)
  5. Submit with payment
  6. ✅ Should show success popup and redirect to dashboard!

⚠️ Troubleshooting:

If you see "Failed to fetch":

  • Backend is not running → Start it using Step 2-3
  • Check if port 8080 is in use by another app

If port 8080 is already in use:

$proc = Get-NetTCPConnection -LocalPort 8080 | Select -First 1 -ExpandProperty OwningProcess taskkill /F /PID $proc

Then restart backend

🎉 Success Indicators:

  • ✅ Backend shows "Started BackendApplication"
  • ✅ Can access http://localhost:8080/api/patent-filing/status/submitted
  • ✅ Form submits without "Failed to fetch" error
  • ✅ Success popup appears with green checkmark
  • ✅ Redirects to dashboard after 3 seconds
  • ✅ Data appears in PostgreSQL `patent_filings` table

📊 Check Data in Database

After submitting a patent filing, verify in PostgreSQL:

psql -U postgres -d my_project_db SELECT * FROM patent_filings ORDER BY created_at DESC LIMIT 1;

💚 Keep the backend terminal window OPEN while using the app!
